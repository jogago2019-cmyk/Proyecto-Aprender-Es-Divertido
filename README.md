# Aprender es divertido
Esta es una app educativa hecha en Flutter para apoyar el aprendizaje de niños. La idea es que sea fácil de usar, visual y divertida.
La aplicación permitir que la maestra cree actividades de lengua para sus alumnos lo realicen.
## ¿Qué hace esta app?

- Permite iniciar sesión como maestra(Usuario,Contraseña)
- Permite seleccionar alumnos
- Muestra actividades de lengua
- Tiene ejercicios para completar palabras
- Tiene ejercicios para ordenar palabras
- Tiene acrósticos
- Tiene lectura de libros PDF con preguntas
- Permite crear y guardar ejercicios nuevos
- Guarda la información localmente en el dispositivo

## Funciones principales

### Lengua
- Completar palabras
- Ordenar palabras
- Acrósticos
- Libros PDF con actividades

### Para la maestra
- Crear ejercicios personalizados
- Ver ejercicios guardados
- Eliminar ejercicios que ya no use
- Gestionar alumnos
- Ver estadísticas


## Requisitos

- Flutter SDK 3.11.3 o superior
- Android Studio o VS Code
- Android o emulador configurado
- Conexión a internet solo si se instala dependencias


## Tecnologías usadas

- Dart
- Flutter
- Material Design
- SharedPreferences
- audioplayers
- image_picker
- permission_handler
- path_provider
- file_picker
- pdfx
- advance_pdf_viewer

## Datos guardados

La app guarda la información localmente en el celular, como:

- ejercicios creados
- alumnos
- progreso o datos de uso
- imágenes relacionadas con actividades

## Uso básico

### Como estudiante
- Abre la app
- Selecciona tu nombre
- Elige una categoría
- Resuelve los ejercicios
- Avanza con las actividades

### Como maestra
- Inicia sesión
- Entra al taller de contenido
- Crea ejercicios
- Agrega imágenes y pistas si quieres
- Guarda los cambios

## Objetivo del proyecto

El objetivo es ayudar a los niños a aprender de una forma más simple, clara y entretenida, usando actividades visuales y juegos educativos.

## Nota

Este proyecto está hecho como trabajo académico y para apoyar la enseñanza en actividades de aprendizaje inicial.
